# Design with Sources, Transforms & Sinks

Build your Apache Spark 4.x pipeline visually by connecting nodes on the canvas.

### Visual Components

- **Sources**: Read batch or streaming data from BigQuery, BigLake Iceberg, Kafka, Pub/Sub, Cloud SQL, Spanner, or Cloud Storage files.
- **Steps**: Filter, project, watermark, window, aggregate, join, deduplicate, or merge CDC records with Catalyst expressions.
- **Sinks**: Write results to BigLake Iceberg, Delta Lake, BigQuery, Kafka, relational databases, or cloud object storage.

### Editing Properties

Click any node on the canvas to open its **Properties Panel** on the right side. Required fields highlight clearly, and every option includes built-in Apache Spark 4.x documentation tooltips.
